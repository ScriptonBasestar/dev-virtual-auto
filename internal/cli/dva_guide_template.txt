## What is DVA?

DVA is a Docker Compose / Kubernetes CLI wrapper. Instead of memorizing long `docker compose exec ...` commands,
you run short aliases defined in `dva.yml`.

## Rules

1. **Always use DVA** — Never bypass DVA with raw `docker compose` or `kubectl` commands if DVA has a command for it.
2. **Discover first** — Run `dva ls` or `dva manifest -f json` to see available commands before guessing.
3. **Lifecycle via DVA** — Use `dva up`, `dva down`, `dva stop` for container lifecycle management.
4. **DVA handles env** — DVA automatically applies environment interpolation, overrides (`.sb/dva/*.yml`), and networking.

```bash
# Lifecycle

# Debugging

dva validate           # Validate dva.yml

```

## Configuration Structure

DVA configuration lives in:
- `dva.yml` — Main config (commands, compose files, environment)
- `.sb/dva/*.yml` — Modular config fragments (merged automatically)
- `dva.override.yml` — Local overrides (typically gitignored)
