> **✅ Completed 2026-07-22** — already applied in `claude-ce-plugin`

## Decision (settled)

The `dva:config` skill content lives **only** in the dva repo
(`claude-plugin/skills/config/`). `claude-ce-plugin` keeps a lightweight
**reference/pointer** and ships **no** dva-config prompt/skill content — no dual
management.

Trade-off explicitly accepted: `tool:dva-config` was globally installed (auto-
triggered in any session, including consumer/devbox projects where `dva.yml` is
authored). After removal, the config skill is only available where the dva plugin
is loaded. Single-source-of-truth was chosen over that convenience. If global
availability is later wanted, install/publish the dva plugin globally — do NOT
re-embed content in ce-plugin.

## Why this couldn't be done from the dva-repo session

Cross-repo writes to `~/mywork/scripton/claude-ce-plugin` are blocked by this
session's permission boundary (project-dir scope). Apply the change-set below
from a session scoped to the ce-plugin repo.
